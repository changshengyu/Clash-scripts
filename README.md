# Clash-scripts

适用于 Mihomo / FlClash 的覆写脚本。

## 推荐版本

使用 [`覆写脚本v8`](./覆写脚本v8)。

v8 主要改进：

- GitHub 与 GHCR 使用 GitHub 专用地址进行节点健康检查，自动避开仅能访问测速地址、却无法连接 GitHub 的节点。
- 亚洲自动策略严格按照“日本 → 新加坡 → 台湾 → 香港”降级；每个地区内部自动选择延迟最低的节点。
- 全球自动策略在全部可用节点中按延迟选择。
- 明确校验测速地址的 HTTP 状态码，并在连续失败后主动复测。
- 缩小订阅信息过滤范围，避免误删名称中含“实验”或“测试”的真实节点。
- 节点、策略引用自动去重，减少重复测速和重复选项。
- 通用出口与 GitHub、Steam、AI 等业务策略解耦，避免策略组互相污染。
- 保留订阅或其它覆写脚本中已有的规则提供器。
- Steam 国内下载与国内 CDN 直连，Steam 商店、社区和海外服务走代理。
- 私有地址规则优先于广告拦截，降低局域网服务被误伤的概率。

## 使用

将 `覆写脚本v8` 的完整内容复制到 FlClash 的 JavaScript 覆写中并启用。更新脚本后，建议在 FlClash 中重新应用配置一次，使旧策略选择缓存失效。

脚本不会主动修改 DNS 或 TUN 设置，这两项继续由 FlClash 管理。
